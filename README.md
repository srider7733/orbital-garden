# Orbital Garden

A small neon arcade game about steering a ring through orbiting light. Harvest the gold motes, avoid the void moths, and reach 24 before your three lives are gone.

## Run locally

Requires Node.js 22 or newer. From this repository:

```bash
node serve.ts
```

Open `http://localhost:8080` in a desktop browser. Use Arrow Left/Right or A/D to steer; the mouse also steers the ring. Press Space or Enter to start and restart.
